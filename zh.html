常见问题。

NOTCHLIVE 的总供应量是多少？

总供应量为 11,111 个 NFT，属于同一个池，不分免费/付费。免费和付费铸造都会从同一个池中随机抽取未铸造代币，而不是按画廊顺序，网站画廊仅保留 40 件样品作品。

为什么免费铸造还要收费？

NFT 本身是免费的（0 BNB）。你每次铸造只需支付 0.0001 BNB 铸造费。该费用支付到合约中，之后只有所有者可以提取。没有单独的国库地址。

付费铸造多少钱？

每个 NFT 0.001 BNB。发送总额为 铸造数量 × 0.001 BNB，另加 BNB 链 Gas。

不手动连接钱包可以铸造吗？

可以。在 AI Agent 部分粘贴你的钱包地址——两个提示词会自动填写——然后复制提示词并发送给可以访问 BNB 链钱包的 AI Agent。

可以用 Binance Agent ID 铸造吗？

可以。如果你的钱包持有 Binance Agent ID，无论手动流程还是 AI Agent 流程都可以使用它铸造。
